# Security

Do not disclose vulnerabilities, credentials, private observations or deployment details in public issues.

Use [GitHub private vulnerability reporting](https://github.com/katzimoto/BLE-map/security/advisories/new). Include the affected public commit and a minimal synthetic reproduction. Never attach real captures or credentials. If private reporting is unavailable, wait for maintainers to enable it; do not substitute a public disclosure.

The bootstrap has no supported release yet. Maintainers assess reports on the default branch. Do not deploy it as an evidence collection or surveillance service. A possible credential exposure requires immediate private rotation or revocation before publication work resumes.
