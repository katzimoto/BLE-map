# Data semantics and synthetic provenance

## No observations from the physical world

Every sample is created by `scripts/generate_synthetic.py`, version 1. It reads no source files, network, environment seed or clock. Fixed Python PRNG seeds, integer quantization and canonical sorted-key JSON yield repeatable fixtures. There are no Bluetooth addresses: `synthetic-beacon-001` and similar identifiers are newly invented abstract fixture identifiers. No identifier is derived by hashing an observation. The SHA-256 values in the public fixture manifest describe only generated bytes.

Five 48-second cases use a 200 ms generator step: triangle (seed 101), clock-drift (202), collinear (303), sparse (404) and weak-fit (505). Each invents seven advertiser addresses and two or three receivers. One pair explicitly simulates rotation halfway through the replay; this assigned relationship is never inferred from captured behavior.

Receiver and beacon XY positions are fictional local metres, unrelated to geography. The generator contains their exact parameters. Normal receiver calibration uses distances 1, 2, 4 and 8 m with paired perturbations of −1 and +1 dB. Weak calibration uses 1, 2 and 3 m with −9 and +9 dB perturbations. Simulated RSSI follows `−55 − 20 log10(max(1, distance))` plus seeded Gaussian noise with standard deviation 1.6 dB, rounded to integer dBm and bounded to [−120, −10]. These choices are synthetic parameters, not fitted environmental measurements.

Duplicate packets and timestamp ties are retained in every event array. A rotating address changes its abstract ID at relative 24 seconds. A sparse beacon appears briefly. Drift offsets and slopes are assigned only in the clock-drift case. Invented byte arrays exercise short, malformed and extended-or-concatenated structures; they contain no real local names, serials or vendor content.

## Signal and estimation semantics

**The RF field is not a map.** Stronger RSSI moves inward; direction has no physical meaning. Radius is linear in clamped [−120, −10] dBm. Reference arcs carry dBm only and render behind glyphs. The receiver layout is a separate equal-scale metric XY diagram.

EMA uses `alpha = 1 − exp(−dt/tau)` and holds the last simulated RSSI between receptions. Negative time steps are invalid and zero-duration ties do not advance smoothing. The analytical raw trace is pointwise; the line connects EMA sample estimates. Histogram bins do not replace observations.

For each receiver the position estimator uses a median of distinct `(relative time, RSSI)` readings in the preceding two seconds. Exact duplicate contributions are suppressed only inside the estimator; all original rows remain visible, counted and exported. No independent-sample variance reduction is claimed for correlated receptions.

Calibration fits RSSI against log-distance. The inverse prediction interval solves the quadratic inequality for the prediction band, including regression uncertainty. If the slope is unresolved, a finite point interval is withheld. See the [NIST calibration reference](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/calibrat.htm). The model is conditional on the synthetic Gaussian assumptions, with a residual scale floor of 1 dB; its nominal interval is not a validated real-world accuracy guarantee.

Three recent receivers, corrected clocks, finite calibration intervals and nondegenerate geometry are required for a point fix. A robust weighted objective includes regression prediction variance and searches a fixed [−18, 18] m fictional square at 0.4 m steps. Evidence disagreement or boundary contact yields no fix. The sensitivity radius is the square root of the largest eigenvalue of the inverse local information matrix, expressed in metres. It omits systematic model error and is not a 95% confidence region. Rendering caps its visual radius; the indicator is qualitative. Changing receiver positions changes the assumed model, not the generated evidence.

## Schema

`public/fixture.schema.json` and `public/project.schema.json` are closed JSON Schema 2020-12 schemas. The six arrays `t`, `rssi`, `beacon`, `receiver`, `counter_ms`, `variant` have equal length, bounded indices and nondecreasing time. Every row is preserved. The browser constructs typed arrays and a `Uint32Array` index per abstract address, using binary search for seek boundaries.

The fixture manifest records synthetic case labels, generated file names, row counts and generated-byte hashes. A project embeds one exact approved fixture plus its view. Import is bounded to 2 MB and rejects altered observations, extra fields, unsupported identifiers and incompatible receiver layouts. Schema validity alone is insufficient: generated-byte provenance must also match.
